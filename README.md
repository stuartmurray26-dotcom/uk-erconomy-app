---

## Features

- **Bank Rate History** – 258 records of every Bank of England rate change. Browse, filter by year, paginate.
- **Inflation History** – Annual UK CPI inflation 1989–2025 with year-on-year analysis.
- **Detail Pages** – Each record shows its context: change from previous rate, rank among all records, and the corresponding inflation figure.
- **Comparison View** – Side-by-side chart of bank rate vs inflation with the calculated real rate.
- **REST API** – JSON endpoints at `/api/bank-rates`, `/api/inflation`, `/api/compare`.
- **Error handling** – Custom 404 and 500 pages.

## Running locally

```bash
# 1. Clone / unzip
cd uk_economy_app

# 2. Create a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run (auto-seeds DB on first launch)
python app.py
```

Visit `http://localhost:5000`.

### Seed manually

```bash
flask --app app seed
```

## Deploying to Render

1. Push repo to GitHub.
2. Create a new **Web Service** on [render.com](https://render.com) and connect the repo.
3. Render picks up `render.yaml` automatically.
4. The first request seeds the database from the bundled CSV files.

### Environment variables

| Variable | Value |
|----------|-------|
| `SECRET_KEY` | Auto-generated by Render |
| `DATABASE_URL` | SQLite path (default) or a PostgreSQL URL |

---

## Maintenance

- **Adding new inflation data**: append a row to `data/inflation.csv` and re-run `flask --app app seed`.
- **Changing the database engine**: set `DATABASE_URL` to a PostgreSQL connection string; no code changes needed.
- **Running in production**: `gunicorn "app:create_app()" --bind 0.0.0.0:8000 --workers 2`
